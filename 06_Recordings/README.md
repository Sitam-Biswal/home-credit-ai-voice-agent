# Recordings To Add

Deploy `../01_System_Prompt/system_prompt.md` in Retell AI, Bolna, or a similar supported voice-agent platform, then record the scenarios from `../03_Testing/test_matrix.csv`.

Recommended minimum recordings:
- T01 Perfect eligible
- T02 Agricultural
- T03 Cash income
- T04 Missing originals
- T07 > ₹75 lakh
- T09 Existing loan
- T10 EMI reduction
- T11 Out-of-order
- T12 Busy customer
- T13 Contradiction

Place exported files here using names such as:
`T01_perfect_eligible.wav`
`T02_agricultural.wav`

Do not claim these files are real recordings until they have actually been generated.
