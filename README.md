# Home Credit LAP AI Voice Agent — Submission Package

This package is prepared from the supplied SalesAgents AI assignment reference material.

## Included
- `01_System_Prompt/system_prompt.md` — complete production-style system prompt.
- `02_Approach_Document/` — approach, business rules and state machine.
- `03_Testing/test_matrix.csv` — 16 test scenarios.
- `04_Transcripts/` — sample transcripts for all 16 scenarios.
- `05_Simulator/` — small deterministic state/first-missing-question helper.
- `06_Recordings/README.md` — exact steps for adding real voice recordings.

## Important
The assignment requires actual test audios, audio transcripts and a public call-recording/log link. This package does not fabricate those artifacts. Generate them after deploying the prompt on Retell AI, Bolna, or a similar voice-agent platform.

## Submission checklist
[ ] System prompt
[ ] Voice agent deployed
[ ] Real test audios
[ ] Real transcripts from those calls
[ ] Public recording/call-log link
[ ] Approach document

## Core differentiator
Extract first → validate second → update state third → ask the next missing question fourth.
