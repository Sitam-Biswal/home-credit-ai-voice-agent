# Business Rules & Decision Table

Source: assignment reference material.

| Variable | Accepted / Rule | Failure behavior |
|---|---|---|
| Property type | Residential, Commercial, Industrial | Agricultural → immediate disqualification |
| Ownership | Sole or Joint | Both eligible |
| Original documents | Originals available for verification | Originals unavailable / photocopies only → disqualify |
| Loan amount | Up to ₹75 lakh | Above ₹75L → offer ₹75L; if declined, end |
| Occupation | Salaried or Self-employed | Do not invent other eligibility rules |
| Income mode | Bank | Cash → disqualify |
| Market value | Capture approximate current value | No minimum threshold specified |
| Tenure | 3–15 years inclusive | <3 or >15 → disqualify |
| Existing property loan | Fresh-loan flow not applicable | Specialist/loan-transfer branch → end |
| EMI reduction request | Transfer branch | Specialist/loan-transfer branch → end |
| Busy | Callback time | Capture callback time → end |
